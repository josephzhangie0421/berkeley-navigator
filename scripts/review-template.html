Academic review desk

Read-only review snapshot. These candidates are not approved academic facts. Nothing here publishes automatically. Verify the official source before running any generated approval command.

1. Inspect the source and catalog year. 2. Check metadata, wording, aliases and nested logic. 3. Keep unsupported conditions unknown. 4. Name the reviewer and confirm checks. 5. Run the explicit approval command in your own terminal.

To correct a record, download its JSON, edit it, then run .venv/bin/python scripts/manage.py validate FILE and .venv/bin/python scripts/manage.py stage FILE. Refresh this desk with .venv/bin/python scripts/review_report.py.
